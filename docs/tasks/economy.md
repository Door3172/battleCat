## [EC-001] 章節環境機制：平衡試玩

- 優先度：中

**需求**

- 做了什麼：
  1. **試玩方法**：手動試玩的樣本太少，看不出勝率差異，所以寫了一個 headless 模擬器（放在我的暫存目錄，**不進 repo**）：直接 import 真正的 `world.js` / `ai.js` / `environment.js`，照抄 `Battle.jsx` 主迴圈的生怪邏輯，由 bot 操作（依編成順序召喚、前 90 秒升收入、敵人靠近主堡或 ≥4 隻就放大砲）。bot 有兩種出兵策略（狂出肉盾 / 限制肉盾數量），每種情況取勝率較高的那個，代表「還算會玩的玩家」。
     - 玩家強度：以「打到該關之前的累積首通獎勵 + 起始 300 金幣」為預算 ×0.6~×4，用貪婪法依序升級（研究力、大砲、主堡、編成貓）與購買商店貓（忍者→武士→騎士→維京）。

  **評估**
  - **夜晚的風險 / 報酬：目前不值得**。在「剛好打得過」的戰力下，夜晚讓勝率明顯下降，多出的魚（整場約 +10~15%）補不回來；戰力充足時則只是多一點魚。另外試了「夜晚預告時先存魚」的聰明策略：1-5 勝率 78% → 98%，表示看準時機有回報，這個設計方向是對的，只是數值偏兇。
  - **潮汐：整體偏向幫助玩家**，不是威脅。漲潮時雙方一起被往左推，相對位置不變；退潮時把貓咪送到敵堡、敵人被壓在敵堡邊界，實際效果是「機會」大於「危險」。考慮到 2-5 依賴潮汐才打得過、2-20 BOSS 關也因此變得可打，**建議維持現值**，不減弱。推力降到 24/20 的測試：2-5 在較低戰力下變回打不過、2-20 勝率從 51% 掉到 30%。
  - **預告時間**：夜晚 5 秒、潮汐 4 秒，都大於主力貓的召喚冷卻（2~7 秒），足夠召喚 1~2 隻或放大砲；bot 用預告存魚/出兵也確實有效。**建議維持**。（無法模擬真人反應時間，這點是判斷而非數據。）
